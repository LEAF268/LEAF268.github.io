このアプリについて

pubg-timestamps(以下「本アプリ」)は、YouTube チャンネル「LEAF」の運営者が、自分の動画にタイムスタンプのコメントを投稿するために使う個人用ツールです。

使う Google のデータ

本アプリは YouTube Data API を使い、運営者本人の YouTube アカウントで次のことだけを行います。

  • 自分のチャンネルの動画に、タイムスタンプのコメントを投稿する
  • 本アプリが投稿したコメントを、書き直す
  • コメントを投稿する動画の情報(動画ID・タイトル)を読む

データの保管

ログイン後に Google から受け取る認証情報(トークン)は、運営者のパソコンの中だけに保存します。外部のサーバーには送りません。

データの共有

本アプリが Google から受け取ったデータを、第三者に販売・提供・共有することはありません。広告にも使いません。

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本アプリのアクセスを取り消せます。
